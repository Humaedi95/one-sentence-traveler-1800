## The entry

`main.ts` writes a single sentence to `/output/entry.txt`. The sentence
explains the modern internet to a time traveler who has just stepped out
of the year 1800, using only words and things a person from that year
would already know — roads, letters, books, spoken words, friends, and
the blink of an eye. No word in it was coined after their time, and it
holds one image instead of a list of features:

> Think of every road on earth joined into one, so a letter, a book, or a spoken word can reach any friend in the time it takes to blink.

135 characters, one sentence.

## Run it

Requires Node 22 or later (TypeScript runs as-is):

```sh
node main.ts
```

It creates `/output` if needed, writes the sentence to
`/output/entry.txt`, and prints the sentence with its character count.
